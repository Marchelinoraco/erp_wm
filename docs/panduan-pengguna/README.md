# Panduan Pengguna

Folder ini menjawab satu pertanyaan: **"bagaimana saya memakai fitur ini?"** — ditulis untuk staf yang memakai sistem sehari-hari (sales, akuntan, admin), bukan untuk developer. Isinya langkah demi langkah, aturan yang berlaku, dan pesan yang muncul di layar saat sesuatu ditolak.

Bedanya dengan [`design-system/`](../design-system/README.md): folder itu menjelaskan **bagaimana fitur bekerja** (alur bisnis, model data, route) untuk orang yang akan mengubah kodenya. Folder ini menjelaskan **bagaimana memakainya** untuk orang yang akan menjalankan pekerjaannya.

## Daftar panduan

| Panduan | Untuk peran | Isi singkat |
|---|---|---|
| [rincian-profit.md](rincian-profit.md) | Sales, Akuntan, Admin | Mengisi dan mengoreksi biaya modal tour, termasuk setelah invoice disetujui |

## Konvensi

- **Satu berkas per fitur**, nama berkas kebab-case (`nama-seperti-ini.md`).
- Ditulis dari **pembacaan kode**, bukan dari dokumen desain — kalau kode berubah, panduannya ikut diperbarui.
- **Pesan error dikutip persis** seperti yang muncul di layar, supaya staf bisa mencocokkan dengan yang mereka lihat.
- Disusun **berbasis skenario** (situasi yang dihadapi pengguna), bukan per tombol atau per layar — aturan penting dijelaskan di tempat aturan itu menggigit.
- Tanpa tangkapan layar untuk saat ini; tampilan berubah lebih cepat daripada aturannya.
